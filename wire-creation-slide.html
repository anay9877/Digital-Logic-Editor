onWireMouseDragged(x, y) Snap pointer. A straight route previews one leg; otherwise preview an L-bend. After 20 px, lock orientation with horizontalFirst = (|dx| >= |dy|). Preview is not committed.
↓
onWireMouseReleased(x, y) → handleWireRelease(x, y) Snap release position; resolve destination: Port → PointNode → WireSegment. If none is hit, reject: wires cannot end in empty space.
Validate in order; first error rejects the connection:
checkWireLength(...) checkInputToInput(...) checkInputAlreadyConnected(...) checkSingleDriver(...) checkCombinationalCycle(...) checkDuplicateConnection(...)
Only after validation passes is a destination WireSegment split. Release records history in a finally block.

What splitting does

Circuit.splitSegmentAtJunction(A—B, x, y) projects and snaps the click, creates node J, removes A—B, and adds A—J plus J—B.

AB

J becomes a junction when the new segment is registered and its connected-segment count reaches 3.

Timing detail to remember

Start-on-wire: split happens on mouse press, before release validation.
End-on-wire: split happens after validation passes.
After commit: notifyRender() redraws; recordChange() snapshots history.

Hit-test order matters: Port → PointNode → WireSegment.WireSegment = one straight edge · PointNode = shared connection point
