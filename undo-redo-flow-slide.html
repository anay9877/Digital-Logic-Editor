EditorController.undo() → HistoryManager.undo()
Entry and guard

Toolbar callback or Ctrl+Z calls undo(). If drawingWire, return to avoid replacing the model mid-wire.

recordChange() safety check

Snapshot current circuit first; record() is a no-op if that state is already current.

HistoryManager.undo()

If undo is unavailable, return null. Otherwise, push current onto redo, set current to popUndo(), fire, and return the prior JSON.

Redo one operation
EditorController.redo() → HistoryManager.redo()
Entry and guard

Toolbar callback, Ctrl+Y, or Ctrl+Shift+Z calls redo(). If drawingWire, return.

recordChange() safety check

Capture any unrecorded current state before moving through history.

HistoryManager.redo()

If redo is unavailable, return null. Otherwise, push current onto undo, take the newest redo snapshot as current, trim, fire, and return its JSON.

canUndo() · canRedo()

Report whether their stack is non-empty; HistoryManager.fire() updates toolbar button states.

applySnapshot(next)

Uses the same restore path as Undo: rebuild circuit, clear selection and in-progress wire state, then redraw.

New edit after Undo: record(after) clears redoStack, so redo is no longer available along that history branch.
Stack direction: newest snapshots are at the front. trim() removes the oldest from the back. Restore recreates model objects from JSON; it does not reverse each edit individually.
